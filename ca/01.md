# Assessment: Python Package Development with `uv` and `pytest`

## 1. Develop the `Strops` Class

Develop a Python package named **`strops`** containing a class called **`Strops`**.

The class must implement the following **10 string-processing functions**:

| # | Function | Requirement | Example |
|---|---|---|---|
| 1 | `span(substr)` | Return the start and end positions of the first occurrence of `substr` | `"hello world"` → `"world"` → `(6, 11)` |
| 2 | `word_count()` | Return the number of words in the string | `"Python is fun"` → `3` |
| 3 | `most_frequent_char()` | Return the character occurring most frequently | `"banana"` → `"a"` |
| 4 | `unique_chars()` | Return characters that occur exactly once | `"swiss"` → `"wi"` |
| 5 | `is_palindrome()` | Determine whether the string is a palindrome | `"madam"` → `True` |
| 6 | `is_anagram(other)` | Determine whether the string and `other` are anagrams | `"listen"` + `"silent"` → `True` |
| 7 | `remove_punct()` | Remove punctuation while retaining letters, digits and spaces | `"Hello, World!"` → `"Hello World"` |
| 8 | `longest_word()` | Return the longest word in the string | `"Python makes programming fun"` → `"programming"` |
| 9 | `char_frequency()` | Return the frequency of each character | `"hello"` → `{'h':1,'e':1,'l':2,'o':1}` |
| 10 | `mask(n)` | Mask the first `n` characters with `*` | `"9876543210"` → `"******3210"` when `n=6` |

The implementation should demonstrate appropriate use of Python constructs such as **functions, loops, conditions, lists, sets and dictionaries**.

Do not simply expose Python's existing string methods as wrappers.

## 2. Create the Package Using `uv`

Create and manage the project using **`uv`**.

The project should have an appropriate package structure, for example:

```text
strops-project/
│
├── pyproject.toml
├── README.md
│
├── src/
│   └── strops/
│       ├── __init__.py
│       └── strops.py
│
└── tests/
    ├── test_search.py
    ├── test_counting.py
    ├── test_palindrome_anagram.py
    └── test_processing.py
```

Use `uv` to:

- Initialize the project.
- Create/manage the Python environment.
- Add `pytest` as a development dependency.
- Build the package.
- Install the package.
- Run the test suite.

The project must contain a valid **`pyproject.toml`**.

The package should be buildable into standard distribution files using:

```bash
uv build
```

## 3. Develop Comprehensive `pytest` Tests

Develop a pytest test suite for **all 10 functions**.

Tests must be placed separately from the application code and must use **multiple test files**.

Each function must have **at least two meaningful test cases**, giving a minimum of:

```text
10 functions × 2 tests = 20 test cases
```

Tests should include appropriate:

- Normal cases
- Boundary cases
- Empty strings
- Single-character strings
- Missing substrings
- Repeated characters
- Multiple words
- Punctuation
- Matching and non-matching anagrams
- Palindromes and non-palindromes

For example:

```python
def test_is_palindrome_true():
    s = Strops("madam")
    assert s.is_palindrome() is True
```

and:

```python
def test_is_palindrome_false():
    s = Strops("python")
    assert s.is_palindrome() is False
```

The complete test suite must execute successfully with:

```bash
uv run pytest
```

## 4. Test the Packaged Application Inside a Virtual Environment

Demonstrate that the project works as an independently installable Python package.

Create a virtual environment using `uv`:

```bash
uv venv
```

Activate the environment and verify that the Python interpreter belongs to the virtual environment.

Build the package:

```bash
uv build
```

Install the generated package into the virtual environment.

Verify that the package can be imported:

```python
from strops import Strops
```

Perform a few manual checks, for example:

```python
s = Strops("Hello, World!")

print(s.word_count())
print(s.remove_punct())
print(s.is_palindrome())
print(s.char_frequency())
```

Finally, execute the complete pytest suite from the environment and demonstrate that **all tests pass**.
